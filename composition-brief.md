# Hyperframes Composition Brief: Mobbin

## Objective
Create a short launch-style brag video for Mobbin in a modern motion graphics visual style inspired by Muse.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: landscape — 1920x1080
- Duration: 24.0 seconds

## Source Material
- Product URL: `https://mobbin.com/`
- Product name: Mobbin
- Tagline / strongest claim: "Where teams and agents find designs that work"
- Key UI or visual moment to recreate: Floating mobile mockups, searchable platform tags (iOS, Android, Web), multi-step flow diagrams, and MCP agent integration.
- Copy that must appear verbatim:
  - "Where teams and agents find designs that work"
  - "400,000+ searchable screens"
  - "Inspect Full Real-World Flows"
  - "Give your AI agents access to Mobbin"
  - "Save hours of UI & UX research"

## Creative Direction
- Tone preset: cinematic
- Creative direction: sleek, high-contrast, modern UI motion graphics like Muse
- Interpretation: Deep dark obsidian canvas (`#0B0F17`), razor-sharp white typography, electric cobalt accents (`#2563EB`), floating device frames in 3D perspective, smooth spring eases, and synced rhythmic cuts.
- Angle: The world's largest design reference library that product teams and autonomous agents use to eliminate design guesswork.
- Hook: Bold typography and cascading phone mockups landing in 3D isometric stack.
- Outro / punchline: "Save hours of UI & UX research. mobbin.com"
- Avoid:
  - Generic SaaS buzzwords
  - Slow uninspired transitions
  - Abstract filler graphics

## Visual Identity
- Background: #0B0F17 (deep obsidian space)
- Text: #F8FAFC (primary white) / #94A3B8 (muted slate)
- Accent: #2563EB (cobalt blue)
- Display font: Inter / sans-serif
- Body font: Inter / system-ui
- Visual references from the project: Mobbin device cards, search filter badges, multi-step flow connectors, and MCP agent terminal badge.

## Storyboard
1. Scene 1: The Hook (0.0s - 4.0s) — "Where teams and agents find designs that work." 3 mobile mockups float in with 3D perspective tilt.
2. Scene 2: The Scale (4.0s - 9.0s) — "400,000+ Searchable Screens." Filter tags illuminate [iOS] [Android] [Web] [Flows].
3. Scene 3: Deep User Flows (9.0s - 14.5s) — "Inspect Full Real-World Flows." 3 linked onboarding & paywall screens expand horizontally with glowing connectors.
4. Scene 4: Agents & MCP (14.5s - 20.0s) — "Give your AI agents access to Mobbin." MCP card pulses with electric blue glow and JSON function call.
5. Scene 5: Outro & Logo (20.0s - 24.0s) — "MOBBIN" wordmark resolves with wide letter-spacing. Subtitle: "Save hours of UI & UX research. mobbin.com"
